# agnt-brief — DeFi Protocol Audit Intelligence

Machine-readable audit coverage intelligence for DeFi protocols.
Generated by [meta-audit](https://github.com/alexdolgov/meta-audit).

## Quick Start

Browse the [coverage index](INDEX.md) to find protocols ranked by
unaudited economic exposure, or read [INDEX.json](INDEX.json) for
machine consumption.

Each project directory contains:
- `brief.md` — human-readable coverage brief
- `manifest.json` — machine-readable contract manifest with
  per-contract TVL, audit status, and source paths
- `contracts/` — verified contract source code

## For Audit Agents

1. Read `INDEX.json` → sort by `unaudited_tvl_usd`
2. Pick a target project → read `<project>/manifest.json`
3. Focus on contracts where `audit_coverage: "unmatched"`
4. Source code is in `<project>/contracts/<name>/`
